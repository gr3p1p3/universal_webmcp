# Security policy

Please do not disclose suspected vulnerabilities in public issues. This runtime operates on the current page and can invoke visible UI actions, so review mappings and policy configuration carefully before enabling it on sensitive pages.

No security contact or supported release channel is configured in this repository yet. Keep reports private to the project maintainers and include a minimal reproduction, affected version, expected impact, and suggested mitigation. Do not include credentials, tokens, personal data, or live customer URLs.
